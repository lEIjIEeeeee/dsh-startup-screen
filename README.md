# dsh-startup-screen

DeepSeek Harness 的启动界面与启动动画插件。

黑幕 DeepSeek 标识 → 过曝洗白 → 暖白「技术档案」底板 → 五步交互式访问授权 →
色散故障揭幕。

> 当前版本 **1.4.0**：新增 Canvas 活体光场、环境光效开关、真实数据面板、
> 准星刻度 / 数据环 / 雷达扫描、镜头推进与终幕撕裂带，以及读取宿主真实 DSH 版本的 REV 行。

> 本仓库是 [6shenhonghong9/dsh-startup-screen](https://github.com/6shenhonghong9/dsh-startup-screen) 的 fork。
> 1.4.0 的 Canvas 光场、氛围层、逐字解码、准星增强与金属鲸鱼等视觉方案，
> 参考自 [QIFANAI/dsh-startup-screen](https://github.com/QIFANAI/dsh-startup-screen) v1.6.0（MIT）。
> 插件市场里的 `dsh-startup-screen` 目录页属于原作者项目，不是本仓库；
> 本仓库不通过该市场分发。仓库地址：[lEIjIEeeeee/dsh-startup-screen](https://github.com/lEIjIEeeeee/dsh-startup-screen)。

## 功能

**开机序列**　冷启动时播一段完整的开机动画，六幕连贯：厂牌标识 → 过曝洗白 →
暖白底板 → 五步授权 → 揭幕。中央准星带 48 格刻度、40 格数据环与雷达扫描扇区，
缺口留在正下方，不会挡住底部文字。

**Canvas 活体光场**　底板后面是一层实时 Canvas：星尘、贝塞尔流光、边缘数据雨与底部水线，
配合暖冷光斑和体积光。中心区域自动降亮，不压文字；同一台机器构图稳定。
可以在设置里关掉「环境光效」，低端机也能保持干净。

**真实版本行**　左上角 REV 行读取宿主的真实 DSH 版本与 profile，不是写死的装饰；
取不到时保留旧占位并自动重试。

**真实数据面板**　左侧两行模型 / 沙箱 / 包数，右侧五行自检清单（PROFILE / BUNDLES /
MODEL / SANDBOX / SESSIONS），底部一条会走动的信号波形。都来自宿主真实数据，
取不到的项显示 `—`。

**液态玻璃底板**　底板、黑幕可以改成半透明磨砂玻璃：整窗重磨砂，文字、线条、准星保持锐利。
玻璃不透明度、磨砂模糊、玻璃饱和度、背景模糊各自独立可调，随调随生效；默认关闭，
想要透出桌面时在设置里打开。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像终端在接收数据。

**真声台词 + 界面音效**　前五句台词取自原片真声，终幕欢迎语是自制落幕词（3.73 秒）；
界面音效取自同一段素材。浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**语音没播完不会推进**　每一步停留多久由实际音频时长决定。你点得快也不会把语音掐断。

**两套主题**　暖白与暗色，版式、文字位置、进度条与准星完全一致，只换底色与文字反相。

**三十四项设置**　身份名称、编号、权限等级、配色、速度、音色、语速、
开口留白、环境光效、每处文案……都能在设置页实时改，改完立即生效。设置页带分类目录与常驻的底部操作条。

## 安装

### 从 GitHub 安装本 fork（推荐）

```bash
dsh plugin --profile web add https://github.com/lEIjIEeeeee/dsh-startup-screen.git
```

桌面端（DeepSeek Harness Desktop）同样支持，profile 换成 `desktop`：

```bash
dsh plugin --profile desktop add https://github.com/lEIjIEeeeee/dsh-startup-screen.git
```

> 插件市场里的 `dsh-startup-screen` 是原作者 6shenhonghong9 的版本，不是本 fork。
> 两者包名相同，不能共存；装本仓库前请先卸载市场版本。

### 本地包安装

```bash
dsh plugin --profile web add ./dsh-startup-screen-<版本>.tgz
```

桌面端（DeepSeek Harness Desktop）同样支持，profile 换成 `desktop`：

```bash
dsh plugin --profile desktop add ./dsh-startup-screen-<版本>.tgz
```

> 部分 DSH 版本会拒绝在终端里操作 `desktop` profile（提示 managed exclusively by the
> Electron application），此时改用桌面端的「插件」页安装即可。

Windows 上也可以解压 release 压缩包后**双击「安装.cmd」**，脚本会自动识别
`web` / `desktop` 两个 profile 并逐个安装。

**装完重启 dsh web 或桌面端**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile / DSH **desktop** profile（标题栏透明仅 Windows 桌面端） |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-startup-screen
```

## 开发

源码在 `src/`，`lib/` 是构建产物（已提交，安装时直接使用）：

- `src/index.js`：宿主入口，只做路径计算与装配
- `src/host/config.js`：配置读写（原子落盘）
- `src/host/facts.js`：启动信息采集（环境、版本、模型、会话数）
- `src/host/routes.js`：5 条 HTTP 路由与来源校验
- `src/host/inject.js`：`index.html` 首屏注入
- `src/shared/`：三个运行时共用的默认值、校验规则、路由常量
- `src/splash/`：启动动画与样式
- `src/client/`：设置面板
- `src/assets/`：音频素材

改完源码运行 `npm run build` 重新生成 `lib/`；提交前运行 `npm run verify`（lint + 类型检查 + 四套冒烟测试）。CI 会检查 `lib/` 是否与源码同步。

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

设置页分为 **播放 / 外观 / 声音 / 内容 / 关于** 五页，左侧菜单切换；底部保存栏固定在内容区底部。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次会话 | `每次会话` 一个浏览器会话播一次 / `总是` 每次刷新都播 / `每天` 一天一次 |
| 主题 | 暖白 | `暖白` 参考片原色 / `暗色` 暗底板 |
| 液态玻璃 | **关** | 底板与黑幕改成半透明磨砂玻璃：整窗重磨砂、文字保持锐利；默认关，想透出桌面再开 |
| 玻璃不透明度 | 75% | 15% – 95%，越低越透；0.75 时背后是暖白模糊而不是灰 |
| 磨砂模糊 | 22 px | 0 – 60 px，玻璃自身的磨砂 |
| 玻璃饱和度 | 160% | 100% – 200%，越高越通透 |
| 背景模糊 | 28 px | 0 – 80 px，直接糊应用本体；20–30 px 最像照片，超过 60 会糊成纯色 |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 要求确认 | 开 | 第 1、2 步是否等你点按钮才继续 |
| 允许跳过 | 开 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 默认 | 作用 |
|---|---|---|
| 身份名称 | `JOYCE MOORE` | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | `0087` | 第二步身份卡上的编号，建议填数字 |
| 权限等级 | `3` | 第二步身份卡上的权限等级 |

### 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 真声素材 | `真声素材` 用内置录音 / `系统 TTS` 用浏览器合成音 |
| 音色 | 自动 | 只在用系统 TTS 时有效。留空 = 自动挑一个女声 |
| 语速 | 0.88 | 只在用系统 TTS 时有效。越慢越有旁白感 |
| 音调 | 0.85 | 只在用系统 TTS 时有效。调低更沉稳，1.0 以上会像客服播报 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |
| 开口前留白 | 240 ms | 提示音响过之后停多久再开口，0 – 1200 ms |

### 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进、按钮确认的「哒」声 |
| 音效音量 | 0.5 | 界面音效音量（不影响台词） |
| 音效来源 | 内置素材 | `内置素材` 用录音 / `现场合成` 用代码合成 |

### 视觉

| 选项 | 默认 | 作用 |
|---|---|---|
| 环境光效 | 开 | Canvas 星尘 / 流光 / 数据雨 + 暖冷光斑；低端机或想更安静时可以关闭 |
| 强调色 | `#ff7500` | 阶段条、进度条、准星的橙 |
| 故障色 A / B | `#ff3b30` / `#2971b8` | 揭幕那下色散故障的红与蓝 |

### 文案

| 选项 | 默认 | 作用 |
|---|---|---|
| 品牌三行 | `DEEPSEEK` / `SYNTHESIZE INTELLIGENCE` / `HARNESS OS` | 左上角品牌块 |
| 黑幕三行 | `深度求索` / `DEEPSEEK` / `DEEPSEEK HARNESS` | 开场黑幕上的字 |
| 终幕方框 | `DEEPSEEK HARNESS` | 揭幕后中央的黑底白字框 |
| 页脚 | `POWERED BY DEEPSEEK` | 右下角页脚 |
